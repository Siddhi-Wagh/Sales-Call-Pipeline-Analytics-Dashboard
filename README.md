# 📊 Sales Call & Pipeline Analytics Dashboard
End-to-end Power BI solution for automated sales call data consolidation, performance analytics, pipeline monitoring, scheduled refresh, and team reporting.

## 📌 Project Overview

This project showcases an end-to-end Power BI solution developed to analyze sales call activity, team performance, call outcomes, connectivity trends, and sales pipeline metrics.

The solution was designed to consolidate recurring daily call data, transform and prepare the data using Power Query, create interactive analytics using Power BI and DAX, and publish the reports through Power BI Service for team-wide access.

The project demonstrates the complete Power BI reporting lifecycle:

**Data Ingestion → Data Transformation → Data Modeling → DAX → Dashboard Development → Power BI Service → Scheduled Refresh → Workspace → Power BI App**

---

# 🎯 Business Problem

Sales teams generate a large volume of call activity and sales pipeline data on a daily basis. Manually consolidating and analyzing this information can make it difficult to monitor:

- Total sales calls
- Connectivity rates
- Call outcomes
- Sales representative performance
- Call duration and engagement
- Daily and weekly trends
- Opportunities and meetings
- Deals created
- Sales pipeline activity

The objective of this project was to create an interactive reporting solution that provides a centralized view of sales activity and performance metrics.

---

# 💡 Solution

An interactive Power BI dashboard was developed to analyze sales call and pipeline performance.

The solution includes:

- Automated consolidation of recurring daily call data
- Data cleaning and transformation using Power Query
- Interactive sales performance reporting
- Call activity and connectivity analysis
- Call outcome analysis
- Sales representative performance comparison
- Daily, weekly, and monthly reporting views
- Sales pipeline metrics
- Power BI Service deployment
- Scheduled data refresh
- Workspace and Power BI App publishing for business users

# 🔄 Data Preparation Process

## 1. Folder Connector

Recurring daily call data files were connected using the Power BI Folder Connector.

This approach enabled multiple files from a folder to be consolidated instead of manually importing individual files.

---

## 2. Combine Files

The daily call data files were combined into a unified dataset.

This helped create a repeatable data ingestion process for recurring call activity data.

---

## 3. Power Query Transformation

Power Query was used to clean and prepare the data for reporting.

The transformation process included preparing the call data into a consistent structure suitable for analysis and dashboard development.

---

# 📈 Dashboard Features

## 1. Sales Call Overview

The dashboard provides a high-level view of sales call activity.

Key metrics include:

- Total Calls
- Connectivity Percentage
- Call Trends
- Calls by Sales Representative
- Connectivity by Weekday

---

## 2. Call Performance Analysis

The dashboard enables users to analyze call performance based on activity and engagement.

Metrics include:

- Total Calls
- Connected Calls
- Outbound Calls
- Inbound Calls
- Calls Above 1 Minute
- Calls Above 2 Minutes

---

## 3. Call Outcome Analysis

The dashboard tracks different call outcomes to understand sales activity and prospect engagement.

Examples include:

- Interested
- Future Prospect
- Left Voicemail
- No Answer
- Not Interested
- Wrong Number
- Connected
- Buyer
- Agent

---

## 4. Sales Representative Performance

Users can compare sales representative performance based on metrics such as:

- Total Calls
- Connectivity Rate
- Call Duration
- Connected Calls
- Call Outcomes
- Outbound Activity
- Inbound Activity

Sales representative names are anonymized in the portfolio version to protect business and employee information.

---

## 5. Interactive Trend Analysis

The dashboard includes interactive date and trend analysis.

Users can analyze:

- Daily call activity
- Performance trends
- Selected date metrics
- Comparison against overall averages
- Performance indicators

This helps users quickly identify periods of higher or lower sales activity.

---

## 6. Weekday Connectivity Analysis

Connectivity is analyzed across weekdays to identify patterns in prospect engagement.

This helps answer business questions such as:

> Which days have higher prospect connectivity?

Such analysis can help sales teams better understand calling patterns and optimize sales activity.

---

## 7. Sales Pipeline Monitoring

The dashboard also includes sales pipeline metrics such as:

- Opportunities
- Meetings Booked
- Deals Created
- Deal Value
- Meeting Value

This provides visibility beyond call activity and supports analysis across different stages of the sales process.

# ☁️ Power BI Service Deployment

After developing the dashboard in Power BI Desktop, the report was published to Power BI Service.

The deployment process included:

1. Publishing the report to Power BI Service.
2. Managing the report through a Power BI Workspace.
3. Configuring scheduled refresh.
4. Making updated reporting available to users.
5. Publishing a Power BI App for team-wide dashboard access.

---

# 🔄 Scheduled Refresh

Scheduled refresh was configured in Power BI Service to support regular dashboard updates.

This enabled business users to access updated reporting without manually refreshing and republishing the report each time.

---

# 👥 Collaboration and Distribution

The Power BI Workspace was used to manage the reporting solution.

The dashboard was then published as a Power BI App so that other team members could access the reports in a centralized and user-friendly format.
